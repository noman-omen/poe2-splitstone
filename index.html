PoE2 Campaign Tracker

Keyboard shortcuts

Space / Enter
Start run, or split: complete the current zone and start the next
U / Backspace
Undo last split
P
Pause / resume
R
New run (unfinished runs are kept in history)
C
Scroll to current zone
F
Focus mode (only the current act/interlude)
H / E
Hide hints / hide extra info
? / Esc
Show / hide this help; Esc also leaves a text field

Ticking the last required step of the zone you are timing also splits automatically. Hotkeys only work while this window has focus.
